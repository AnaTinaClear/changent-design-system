# Changent Design System

One source of truth for decks, reporting UI, Power BI themes and web apps. Every value is a design token in `tokens/*.tokens.json`. Everything in `dist/` and `powerbi/` is generated by `npm run build` and verified by `npm test`.

## Install

```bash
npm i github:AnaTinaClear/changent-design-system#v2.1.0
```

| Need | Use |
|---|---|
| Plain HTML/CSS | `css/changent-ds.css` (classes) + `dist/tokens.css` (`--cds-*` variables) |
| React + Tailwind v4 + shadcn/ui | `@import "@changent/design-system/tailwind.css";` and `@import "@changent/design-system/fonts.css";` |
| Charts (Recharts etc.) | `import { chart } from '@changent/design-system/tokens'` |
| Power BI | `powerbi/changent-powerbi-theme.json` |

## Rules that apply to everything

- Never hardcode hex values. Use a semantic token.
- Every status gets an icon **and** a label. Color is never the only cue.
- Amber and cyan fills take dark text (`on-fill`). White on them fails.
- Status as text on white uses its `text` variant, not its `fill`.
- Controls use `border.default`. `border.divider` is decorative only.
- Type: 14px minimum for content, 12px only for tooltips, footnotes, legends and axis titles.
- Max 6 colors per visual. Never green beside orange or purple.
- No accent lines under titles, no edge stripes on cards, no blue backgrounds.

Use the **Theme** switch in the toolbar to check light and dark. The **Accessibility** panel runs axe on every story.
